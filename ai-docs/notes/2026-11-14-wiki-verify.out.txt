## $ python fw.py explain mandelbrot
mandelbrot
  formula: z <- z^2 + c, z0 = 0, c = pixel
  how: Escape time: iterate each pixel's c until |z| > R or max_iter. Points that never escape form the set (area ~1.50659). Smooth colour mu = n + 1 - log(log|z|)/log 2 with R >= 256.
  presets: mandelbrot-full, seahorse
  more: references/02-escape-time.md#mandelbrot
