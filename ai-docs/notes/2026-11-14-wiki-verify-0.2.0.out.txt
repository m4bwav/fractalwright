== explain julia
julia
  formula: z <- z^2 + k, z0 = pixel, k fixed
  how: Same loop as Mandelbrot but the pixel is the start point and k is a constant. k inside the Mandelbrot set gives a connected Julia set, outside it a dust. Recipe params.c holds k as two decimal strings.
  presets: julia-dendrite, julia-rabbit
  more: references/02-escape-time.md#julia-filled-julia-sets
exit: 0
== explain mandelbrot
mandelbrot
  formula: z <- z^2 + c, z0 = 0, c = pixel
  how: Escape time: iterate each pixel's c until |z| > R or max_iter. Points that never escape form the set (area ~1.50659). Smooth colour mu = n + 1 - log(log|z|)/log 2 with R >= 256.
  presets: mandelbrot-full, seahorse
  more: references/02-escape-time.md#mandelbrot
exit: 0
