# CODEMAP

- `skills/fractalwright/SKILL.md`: hub skill (workflow; loads `references/` on demand).
- `scripts/fw.py`: CLI. `load_recipe`/`normalise` (recipe schema, presets), `escape_numpy` (five families), `render_array` (NumPy core), `render_rows_py` (pure Python fallback), `write_png` (stdlib PNG), `box_dimension` (batch 1, kept for its tests), `mandelbrot_area`; measure v2 block: `box_analysis` (sizes, offsets, local slopes, verdict, thresholds as constants), `remove_specks`, `lacunarity`, `similarity_dimension`; self-affine block: `spectral_slope`, `semivariogram_h`, `katz_dimension`, `radial_psd`, `profile_analysis`, `heightmap_analysis`, `synth_fbm1d` (Davies-Harte), `synth_fbm2d`; `kronecker_mask` and `KRONECKER`; identify block: `julia_connected`, `mirror_scores`, `identify`; `cmd_*` per command; video block: `sheet`, `zoom_frames`, `morph_frames`, `loop_frames`, `write_video` (frames, `encode_mp4`, animation recipe, `probe_comfy`; the AI pass is `scripts/fw_ai.py`: `build_workflow`, `smooth_residuals`, `run_pass`, `apply`, `write_ai_recipe`), `read_frames`, `probe_video`, `flash_check` (WCAG general and red flash area rule on a cell grid; `swing_walk`, `_box_max_fraction`), `seam_ratio`.
- `scripts/fw_deep.py`: deep zoom (Mandelbrot and quadratic Julia; Julia orbit starts at the view centre, rebases to Z[0]). `reference_orbit` (stdlib Decimal, precision = digits of width + 25), `escape_perturb` (float64 deltas, rebasing, stats: rebased_pixels, rebases), `render_array` (fw.colour, so smooth colouring matches), `direct_counts` (slow per-pixel Decimal proof reference). `fw.py render` routes here below width 1e-12 or with `--deep`.
- `scripts/fw_extra.py`: book-derived commands registered by `fw.py main()` via `register(sub, EXPLAIN)`: `explain logistic|coastline` (+ `--plot`), `attractor-search` (Sprott codes, `orbit_lyapunov` in bits, `correlation_dimension`), `ifs` (`ifs_probabilities`, `chaos_game`, `ifs_envelope`), `terrain` (`diamond_square`, `crease_ratio`, spectral via `fw.synth_fbm2d`), `fif` (`fif`, `fif_dimension`).
- `scripts/fw_gen.py`: generative commands registered by `fw.py main()` via `register(sub, EXPLAIN)`: `flame` (`VARIATIONS`, `FLAME_PRESETS`, `flame_points` vectorised chaos game with |det| default weights from fw_extra, `histogram`, `density_estimate`, `tone_map`, `flame_render`, `flame_score`, `random_flame`, `flame_search`), `lsystem` (`LSYSTEMS`, `lsystem_expand` seeded stochastic, `turtle`, `segments_mask`, `segments_svg`), `attractor` (`ATTRACTORS`, `map_points`, `lorenz` RK4, `density_png`, `attractor_search2` with fw_extra's Sprott ranking).
- `scripts/fw_neighbours.py`: neighbours registered by `fw.py main()` via `register(sub, EXPLAIN)`: `rd` (`RD_PRESETS`, `gray_scott`), `ca` (`elementary`, `parse_bs`, `lifelike`), `tiling` (`regular_segments`, `penrose_triangles`, `tiling_mask` via fw_gen.segments_mask), `kleinian` (`apollonian_circles` Descartes reflection, `circles_mask`, `grandma`, `limit_points` inverse iteration). Tests: `tests/test_neighbours.py`.
- `scripts/fw_3d.py`: `fw.py 3d recipe|render|gate`, registered by `main()`. `FORMULAS3D`, `VIEWS` (per formula target/direction/distance), `REMEDIES`, `default_recipe`, `camera_for` (lazy 60 deg or composed: 40 mm, -12 deg, left third, 4 deg roll), `normalise` (camera made explicit), `uniforms`, `PAGE3D` (inline page, strip draws), `Browser3D`, `run_gate` (JPEGs, sheets, gate.json). Shader: `scripts/page/fractal3d.frag`. Browser only.
- `tests/test_gen.py`: flame determinism and Sierpinski D, L-system Koch D and Hilbert cells, Lorenz D2, Clifford render.
- `tests/test_extra.py`: fw_extra proof bars (period doubling, Lyapunov units, Henon L and D2, |det| density, envelope containment, creases, FIF pass-through and D).
- `scripts/fw_serve.py`: explorer. `parse_hash`/`hash_to_recipe`/`recipe_to_hash` (share hash, numbers verbatim, `_js` mimics JS number strings), `float32_ok` (limits `F32_REL_LIMIT`, `F32_WIDTH_LIMIT`), `uniforms` (recipe -> shader uniforms), `page_html` (page with the shader inlined), `Browser`/`browser_render`/`probe_browser` (Playwright, msedge then chrome), `make_server`/`serve` (127.0.0.1 only; GET /, POST /export, POST /render). `fw.py serve`, `export`, `render --route browser` and `doctor` call it.
- `scripts/fw_audio.py`: `fw.py audio`, registered by `fw.py main()` via `register(sub)`. `find_musicwright`/`envelopes` (calls `mw.py envelopes`; `internal_envelopes` NumPy fallback; `FW_MUSICWRIGHT=none` forces it), `drivers` (bass/mid/treb with `one_pole` attack/release, beat accents, chroma hue, loudness), `frame_recipes` (`AUDIO_PRESETS` julia-pulse, mandel-dive), `FlashLimiter` (mirrors `fw.flash_check`, blends a frame back toward the last), `Renderer`/`render_frames` (browser or NumPy), `mux` (ffmpeg, cut to frames/fps), `stream_durations`.
- `scripts/page/audio.html`: live audio page served at /audio (file or microphone, AnalyserNode, same constants as fw_audio.py, JS flash limiter). `tests/test_audio.py`: audio proof bars and the page checks.
- `scripts/page/fractal.frag`: the one WebGL2 shader (five escape-time formulas, smooth colouring as fw.py, cosine or stops palette). `scripts/page/explorer.html`: the page; `window.fw` hooks (drawUniforms, pixels, hashOf, zoomAt, pan, exportRecipe) serve tests and the browser route.
- `tests/test_serve.py`: loopback refusal, page served, hash round trip, export CLI, precision routing; with Playwright: browser vs NumPy per formula, deep view to NumPy, page zoom -> export -> render.
- `tests/test_deep.py`: perturbation proof bars (plain match at 1e-6, Decimal match at 1e-20 and 1e-30, determinism, CLI route).
- `tests/test_fw.py`: proof bars (determinism, symmetry, dimensions, area; batch 2: box verdicts and decoys, specks, Kronecker, lacunarity, Moran, fBm profile and surface, Katz, identify; batch 3 Video: determinism, loop seam, zoom ratio, mp4 frames/fps, flashcheck, AI hook, sheet). Measured errors in TESTS.md.
- `references/01-11`: research by topic. `bench/bench.py`: Step C render-core benchmark.
- `ai-docs/`: HANDOFF, log, plans (design.md = render core and recipe schema; continue prompt), notes.
- Root evergreen unit: `evergreen.json`, RESEARCH, CHANGELOG, LEARNINGS, TESTS, MAINTENANCE, `evals/`, `harvest.json`.
