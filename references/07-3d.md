## 1. Short answer to "would they all look ugly?"

No. The ugliness practitioners complain about has known causes, and each cause has a known remedy:

- **Noise and speckle** come from the distance estimate being only approximate. The DE is "only exact in
  the limit of many iterations and close to the fractal boundary", so a fudge factor < 1 and
  oversampling are the standard fixes (Syntopia V).
- **Banding** comes from integer quantities (iteration count, ray-step count) used for shading.
  Christensen: "Personally, I much prefer noise to banding" (Syntopia II).
- **Aliasing** comes from one ray per pixel (Syntopia II).
- **Flat, depthless images** come from Lambert-only shading with no AO, shadows or fog.
  Fog "adds depth perception" (Syntopia II).
- **False darkening at grazing angles** comes from ray-step AO, the cheap kind (Syntopia II).

So a baseline render with one sample, step-count shading and no AO, shadows or fog will usually look
ugly, and a remedied render need not. The gate should prove that per remedy.

## 2. Ray marching with a distance estimator (the shared core)

Sphere tracing (Hart 1996, The Visual Computer 12(10):527-545, DOI 10.1007/s003710050084).
If a function bounds the distance to the surface (a Lipschitz bound), a ray can step that far and
never pass through the surface. The paper also covers anti-aliasing by approximating cone tracing.
Earlier: Hart, Sandin and Kauffman, "Ray tracing deterministic 3-D fractals", SIGGRAPH 1989,
which first used a distance estimate to render quaternion Julia sets **[unverified]**.

```glsl
// generic march; DE(p) returns a lower bound on distance to the fractal
float march(vec3 ro, vec3 rd, out int steps) {
    float t = 0.0;
    for (steps = 0; steps < MaxSteps; steps++) {
        vec3 p = ro + rd * t;
        float d = DE(p) * Fudge;          // Fudge ~0.5..0.9 reduces overstep noise
        float eps = PixelAngle * t;       // LOD: stop at one pixel's footprint
        if (d < eps) return t;
        t += d;
        if (t > MaxDist) break;
    }
    return -1.0;
}
// normal: finite-difference gradient of DE (Syntopia II); dual numbers avoid choosing eps
vec3 normal(vec3 p, float e) {
    vec2 k = vec2(e, 0.0);
    return normalize(vec3(DE(p+k.xyy)-DE(p-k.xyy),
                          DE(p+k.yxy)-DE(p-k.yxy),
                          DE(p+k.yyx)-DE(p-k.yyx)));
}
```

`PixelAngle * t` ties the hit threshold to the pixel footprint. That gives level of detail for free:
far surfaces stop at coarser detail, which cuts noise and run time. This is the usual practice in
Fragmentarium-style raymarchers **[unverified as a quoted source; standard]**.

## 3. Formulas with DE pseudocode

### 3.1 Mandelbulb (White and Nylander, power 8)

Spherical-coordinate "triplex" power: raise radius to n, multiply both angles by n, add c.
Scalar running derivative DE (Syntopia V, read via mirror):

```glsl
float DE_bulb(vec3 pos) {
    vec3 z = pos; float dr = 1.0, r = 0.0;
    for (int i = 0; i < Iterations; i++) {
        r = length(z);
        if (r > Bailout) break;
        float theta = acos(z.z / r), phi = atan(z.y, z.x);
        dr = pow(r, Power - 1.0) * Power * dr + 1.0;    // running scalar derivative
        float zr = pow(r, Power);
        theta *= Power; phi *= Power;
        z = zr * vec3(sin(theta)*cos(phi), sin(phi)*sin(theta), cos(theta)) + pos;
    }
    return 0.5 * log(r) * r / dr;
}
```

Power 8 is the classic; 7 and 9 look similar (Syntopia V). Typical starting values (not from that
article): Bailout 2-4, Iterations 8-15 **[unverified]**. The bulb has the "whipped cream" problem: away
from the bulbs its surfaces are smooth, stretched swirls. It is the formula most likely to look ugly
at default settings.

### 3.2 Quaternion Julia

z <- z^2 + c in quaternions, c fixed. DE with the running derivative
dz <- 2 z dz (|dz| scalar is enough): `DE = 0.5 * |z| * log|z| / |dz|` (Hart et al. 1989; iq's
quaternion Julia articles) **[unverified]**. Render a 3D slice (fix the 4th component). These are smooth
and blobby by nature, so treat them as the most "plastic-looking" family. Orbit-trap colour and AO
carry them.

### 3.3 Mandelbox (Tom Lowe, 2010)

The step is a box fold, then a ball (sphere) fold, then scale plus c: v = s * ballFold(r, f * boxFold(v)) + c.
The standard Mandelbox uses s = 2, r = 1/2, f = 1 (MathWorld; Imaginary hub; Lowe's site). The
popular art setting is scale -1.5 (artificialnoodles blog). The original sphere fold does both a fold and an
inversion, so most code uses two thresholds (Fractal Forums kalezobox thread summary).

```glsl
float DE_box(vec3 pos) {
    vec3 z = pos; float dr = 1.0;
    for (int i = 0; i < Iterations; i++) {
        z = clamp(z, -FoldLimit, FoldLimit) * 2.0 - z;      // box fold (FoldLimit=1)
        float r2 = dot(z, z);
        if (r2 < MinR2)      { float k = FixedR2 / MinR2; z *= k; dr *= k; }  // MinR2=0.25
        else if (r2 < FixedR2) { float k = FixedR2 / r2;  z *= k; dr *= k; }  // FixedR2=1
        z = Scale * z + pos;
        dr = dr * abs(Scale) + 1.0;
    }
    return length(z) / abs(dr);
}
```

The 0.25 and 1.0 thresholds match the artificialnoodles DE. This is the Syntopia/Fragmentarium form
(loop, folds and `length(z)/abs(dr)` match Syntopia VI, http://blog.hvidtfeldts.net/index.php/2011/11/distance-estimated-3d-fractals-vi-the-mandelbox/, read via mirror, accessed 2026-11-14; that article names minRadius2/fixedRadius2 but gives no values, so 0.25/1.0 come from artificialnoodles). Mandelboxes read as architecture: hard edges and recesses.
AO and fog do most of the work here.

### 3.4 Kaleidoscopic IFS (Knighty): Sierpinski tetrahedron, Menger sponge

Folds, then scale about an offset, then iterate. DE = length(z) * Scale^-n (Syntopia III, via mirror):

```glsl
float DE_tet(vec3 z) {                         // Sierpinski tetrahedron
    int n = 0;
    for (; n < Iterations; n++) {
        if (z.x + z.y < 0.0) z.xy = -z.yx;
        if (z.x + z.z < 0.0) z.xz = -z.zx;
        if (z.y + z.z < 0.0) z.zy = -z.yz;
        z = z * Scale - Offset * (Scale - 1.0);  // Scale 2, Offset (1,1,1)
    }
    return length(z) * pow(Scale, -float(n));
}
// general plane fold (Syntopia III):  z -= 2.0 * min(0.0, dot(z, n1)) * n1;
```

Menger (KIFS form) (the z.z conditional with -0.5*Offset.z*(Scale-1) matches https://www.fractalforums.com/sierpinski-gasket/menger-sponge-45-rotation (search snippet, accessed 2026-11-14); Syntopia III has no Menger code; Scale 3 / Offset (1,1,1) unverified after check (not stated in a fetched source)):

```glsl
float DE_menger(vec3 z) {
    int n = 0;
    for (; n < Iterations; n++) {
        z = abs(z);
        if (z.x < z.y) z.xy = z.yx;
        if (z.x < z.z) z.xz = z.zx;
        if (z.y < z.z) z.yz = z.zy;
        z = Scale * z - Offset * (Scale - 1.0);   // Scale 3, Offset (1,1,1)
        if (z.z < -0.5 * Offset.z * (Scale - 1.0)) z.z += Offset.z * (Scale - 1.0);
    }
    return length(z) * pow(Scale, -float(n));
}
```

Adding a rotation matrix inside the loop (Knighty's KIFS) turns these into an endless family.
The orbit-trap distances double as geometry (Syntopia VIII summary).
IFS solids are crisp. Their ugliness risk is aliasing and moire on repeated holes, not mush.

### 3.5 Pseudo-Kleinian / Apollonian (Knighty)

Apollonian-style: repeated sphere inversions plus a box fold, with a running scale, and DE taken as a
distance to a simple shape (often a cylinder or plane) divided by the scale **[unverified; source:
Fractal Forums Knighty threads, Fragmentarium examples]**. They give cave- and coral-like interiors.
Fog and DOF matter most, since the camera usually sits inside.

### 3.6 Amazing Surf and hybrids

Amazing Surf is a Mandelbox variant that box-folds only two axes, giving sheet or surf forms
(Fractal Forums "amazing box, amazing surf and variations" board) **[details unverified]**.
Hybrids switch formulas per iteration (Mandelbulber, MB3D). A running-derivative DE still works if each
step updates dr by its own scale factor. Mixed analytic and IFS hybrids often need a lower fudge factor.

## 4. Rendering remedies

| Remedy | Ugliness it fixes | Cost | Source |
|---|---|---|---|
| Fudge factor 0.5-0.9 (relaxed step) | speckle, holes, "noise" from DE overstep | 1.2-2x steps | Syntopia V |
| Overstepping with relaxation (step 1.2-1.6x, back off when spheres don't overlap) | slow marching (lets fudge go further) | net faster | Keinert et al. 2014 "Enhanced Sphere Tracing" **[unverified]** |
| Pixel-footprint epsilon (LOD) | sub-pixel shimmer, far-field noise, run time | saves time | standard; Hart 1996 cone-tracing idea |
| Supersampling / AA (render big, downscale; or N jittered rays) | aliasing, jaggies, moire on IFS holes | N x | Syntopia II, V |
| DE-sampled AO (5 samples along normal) | flat lighting, lost recesses | ~5 DE calls/pixel | Syntopia II |
| Step-count AO (cheap) | flat lighting | free | Syntopia I/II; darkens grazing surfaces wrongly |
| Soft shadows, res = min(res, k*h/t) | flat lighting, no shape cue | 1 extra march | iq "soft shadows"; Aaltonen's improved variant reduces banding |
| Fog / depth cue | no depth, busy background, clutter | free | Syntopia II |
| Glow (step-count mixed into misses) | dull silhouettes | free, bands | Syntopia II |
| Orbit-trap colouring (min dist to planes/origin) | monochrome "plastic"; shows structure | ~free | Syntopia II |
| Smooth/continuous colouring, dither | banding from integer counts | free | Syntopia II |
| Depth of field | busy surfaces everywhere; gives a subject | needs many samples | Mandelbulber feature list |
| Path tracing (GI, area lights) | CG flatness; gives the "real object" look | 100s of spp | built as `fw.py 3d render --pt N` (0.4.0+), see "Path tracer" below |
| Composed camera (subject, thirds, inside vs outside) | aimless "whole blob" shots | free | practitioner advice **[source needed]** |
| Lower iterations / smaller power for distant shots | over-busy, noisy surfaces | saves time | follows from LOD; **[unverified]** |

Soft shadow (iq; basic form **[code from prior knowledge]**):

```glsl
float softshadow(vec3 ro, vec3 rd, float mint, float maxt, float k) {
    float res = 1.0, t = mint;
    for (int i = 0; i < 64 && t < maxt; i++) {
        float h = DE(ro + rd * t);
        if (h < 0.001) return 0.0;
        res = min(res, k * h / t);    // k ~ 8..32: larger = harder
        t += h;
    }
    return clamp(res, 0.0, 1.0);
}
float ao(vec3 p, vec3 n) {          // DE-sampled AO (Syntopia II idea)
    float occ = 0.0, w = 1.0;
    for (int i = 1; i <= 5; i++) {
        float h = 0.01 + 0.03 * float(i);
        occ += w * (h - DE(p + n * h)); w *= 0.7;
    }
    return clamp(1.0 - 3.0 * occ, 0.0, 1.0);
}
```

### What practitioners call ugly

- Noise and speckle from approximate DE (Syntopia V).
- Banding from integer step/iteration shading (Syntopia II).
- Aliasing from one ray per pixel (Syntopia II).
- Grazing-angle darkening from step AO (Syntopia II).
- "Whipped cream" / smeared swirls on Mandelbulb surfaces between bulbs. The term is widely used on
  Fractal Forums **[source needed: no primary quote found this pass]**.
- Overly busy surfaces with no focal point. This is a judgement, so the gate should test it with DOF, fog and
  camera framing.

## 5. Look-gate test plan (proposal)

Renderer: one GLSL raymarcher (fractalwright's own, or a headless shader runner). Hold resolution fixed
(1024x1024) and change one variable at a time.

**Baseline ("lazy")**: 1 spp, Fudge 1.0, fixed epsilon 1e-4, MaxSteps 128, Lambert + constant ambient,
single white directional light, no AO, no shadows, no fog, solid grey material, background black,
camera auto-framed on the bounding sphere.

**Remedies** (each alone, then the cumulative stack):
1. Fudge 0.7 + pixel-footprint epsilon.
2. 4x4 supersampling (or 16 jittered spp).
3. DE AO (5 taps).
4. Soft shadows k=16, key light 40 degrees above, plus fill.
5. Exponential fog toward a sky colour.
6. Orbit-trap colour with a 2-3 colour palette.
7. Depth of field (focus on the nearest feature, 64 spp).
8. Composed camera (see views).
9. Full stack: 1-6 plus 8. Then 1-8. Then a path-traced variant if the budget allows.

**Formulas**: Mandelbulb p8, Mandelbox s=2 and s=-1.5, Sierpinski tetrahedron, Menger KIFS with rotation,
quaternion Julia c=(-0.2, 0.6, 0.2, 0.0) **[arbitrary pick]**, pseudo-Kleinian.

**Camera views** per formula:
- V1 "whole object": auto-frame from outside.
- V2 "surface close-up": 1/20 of the bounding radius from the surface, looking along it.
- V3 "interior/cave": inside a recess (box, Kleinian), wide lens.
- V4 "composed": subject on a third, horizon tilted <10 degrees, DOF on.

**Ranking**: pairwise blind, both orders, ties on disagreement (artwright-judge style), plus the owner's
picks. Record each remedy's win rate against the baseline and against the previous stack, and its render time.
Pass rule suggestion: a remedy is kept if it wins >= 70% of pairs on at least half the formulas
at < 3x cost.

## 6. Meshing for 3D print

- **Route**: sample the DE (or the escape inside/outside test) on a voxel grid, then run marching cubes
  at isovalue ~0 (or a small positive offset to thicken), then clean up. Mandelbulber's mesh export works
  this way: a File > Mesh Export dialog, a bounding box, X/Y/Z sampling resolution, PLY output with
  per-vertex colour. It began as adared.ch's mod built on PyMCubes. Release 2.10 notes "added ability to export 3D
  meshes in *.ply format" with automatic bounding box. Mainline source has `src/marchingcubes.cpp`
  (adared.ch; Mandelbulber 2.10 release note; dragonflybsd xref of 2.26).
- **Watertightness**: marching cubes on a closed grid gives a closed surface if the grid boundary sits
  outside the object. Pad the box, or cap it with a box intersection. Fractal detail below the voxel size
  turns into floating islands and thin walls. Keep only the largest component, then remesh and
  check it with polywright-print's `pw.py printable`.
- **Thickening**: mesh DE(p) - t for a wall thickness t (e.g. 0.6-1 mm at print scale) instead of the
  raw zero set, so hairline spikes become printable **[method standard; not sourced]**.
- **Budgets**: a 512^3 grid gives meshes of millions of triangles. Decimate to 0.5-2 M for slicers, and
  less for viewing. **[figures are estimates]**
- **Colour**: per-vertex colour from orbit traps can go to a multi-colour 3MF (polywright `pw.py 3mf`).
- Fractal Forums thread "which software creates cleanest 3d meshes" compares tools **[not read]**.
- **Built (0.6.0)**: `fw.py 3d mesh` in scripts/fw_mesh.py. NumPy ports of the shader DEs, grid of `--res`
  points per side, iso at half a voxel, the inside region holding the deepest point kept (others dropped),
  sealed voids filled, grid padded, then scikit-image marching cubes if installed, else NumPy marching
  tetrahedra (Kuhn split, vertices welded by grid edge, oriented inside-to-outside per tetrahedron). The
  largest face-connected shell is kept (corner-touching specks). Measured 2026-11-14 at 60 mm, skimage:
  Mandelbulb res 200 422,172 tris, 11 s, watertight, 1 shell, `pw.py check --target print-fdm` warn only on
  min_feature (2.7% of the surface under 0.9 mm); Menger level 3 res 136 816,496 tris, 3 s, check pass
  (thinnest 2.25 mm). NumPy engine: Mandelbulb 1.24 M tris 23 s, Menger res 200 6.9 M tris 37 s, both
  watertight. `pw.py printable` rewrites the mesh (and its pre-decimation broke Menger to 4 non-manifold
  edges), so check with `pw.py check`, not printable, unless a fix is wanted.

## 8. Implications for fractalwright

1. Ship its own small GLSL (or numpy/numba CPU) raymarcher with the formulas above, written fresh.
   Use Mandelbulber2's CLI as an optional high-quality backend, run but never vendored.
2. Make the remedied stack the default (fudge, pixel epsilon, AA, DE-AO, soft shadow, fog, orbit-trap
   palette). Keep the lazy baseline only as the gate's control.
3. Rank formulas by risk. The Mandelbulb and quaternion Julia need the most remedies (smooth, creamy).
   Mandelbox, KIFS and Kleinian look good with AO and fog alone.
4. Include a camera-composition step (V2/V4 views). Whole-object shots are the likeliest to look
   generic even with good lighting.
5. Print route: DE grid, then marching cubes (skimage or PyMCubes), then thicken and keep the largest component,
   then decimate, then hand off to polywright-print.
6. Record per-remedy cost so the plugin can choose a budget tier (preview vs final).

## Path tracer (fw.py 3d render --pt N, built 2026-11-14)

Default since 0.8.0 (Mark's pick, askwright set fractalwright-pathtrace-2026-11-14): `3d render|recipe <formula>` uses 256 samples; `--pt 0` returns the shadow + ao look (the blind judge still preferred that for Menger); recipe files keep their own setting.

Own GLSL in scripts/page/fractal3d.frag (`pathTrace`). Diffuse (Lambert) surfaces with the palette albedo
(clamped 0.02-0.85), a sky dome (zenith/horizon gradient) and a sun handled by next-event estimation with a
hard shadow ray; bounce directions cosine-weighted, so the pdf cancels the BRDF and throughput *= albedo.
`bounces` counts indirect bounces (default 2). Random numbers: PCG hash of (pixel x, y, sample index, seed),
so a recipe replays bit-identically on the same GPU and driver. Samples (`spf` per draw, default 4) sum into
an RGBA32F framebuffer by additive blending (needs EXT_color_buffer_float and EXT_float_blend), read back as
float; Python applies the 1/2.2 curve. Recipe key: `"pt": {"samples", "bounces", "seed", "spf"}`.

Measured on the RTX 5060 Ti (ANGLE D3D11), mandelbulb whole view, 512x512, vs a 1024-spp reference:
RMSE 0.0558 / 0.0282 / 0.0144 / 0.0078 at 4 / 16 / 64 / 256 spp, RMSE*sqrt(N) 0.112-0.125 (the
1/sqrt(N) law; the slow rise at 256 is the reference's own noise). Time at 512 px: mandelbulb 0.6 s (64)
/ 1.8 s (256), quatjulia 0.44 / 0.96 s, menger 0.28 / 0.51 s; the default route takes 0.03-0.05 s.
Blind judge (artwright, both orders, brief "reads as a real solid object with convincing light"): path
traced won mandelbulb 2-0 (high) and quatjulia 2-0 (medium); the default won menger 2-0 (low): the sun
flattens the sponge's front faces. Proof script: evals/pt_bench.py.
